# 喵园 CatCampus 部署上线手册（微信云开发）

> **本手册是总纲**，按「微信云开发」为主线把各模块串起来。细分步骤在文末「文档索引」里指向对应文档。  
> 旧 `docs/部署指南.md` 为 MVP 早期版（无云托管 / 虚拟支付 / 最新合规红线），**以本手册为准**。

---

## 0. 部署架构（一张图看懂）

```
          微信小程序（原生，miniprogram/）
                │  仅与云函数通信，不直接访问服务器
                ▼
        云函数 catcampus（单一云函数，表驱动 32 action）
                ├── 云数据库（8 集合）       ← users/schools/cats/sightings/tnr_records/tasks/funds/applies
                ├── 云存储（猫照片/头像）     ← 素材原图
                ├── 识别服务（云托管容器）     ← POST /v1/recognize 等（server/）
                └── 虚拟支付（云函数内 vpay 模块）← 个人虚拟支付（需 MP 后台开通）
                
   管理后台 web/（Vue + Spring Boot + MySQL）  ★可选，非小程序必需
       └── 识别服务（同一云托管）             ← 通过 catcampus.vision.base-url 指向云托管域名
```

**结论**：小程序 + 云函数 + 云数据库 + 云存储 + 识别服务（云托管）这套**全在微信云开发体系内**，无需自购服务器、无需备案自有域名。  
`web/` 后台若也要上线，最省事是也走「云托管」（Spring Boot 容器）+ 云开发「云数据库 MySQL」；否则放在你自有服务器。

## 2. 部署顺序（照着做）

### 2.1 开通云开发 + 初始化

1. 开发者工具 → 云开发 → 开通（按量付费）→ 创建环境，记 **环境 ID**（形如 `catcampus-1gxxxx`）。
2. 改 `miniprogram/app.js` 的 `ENV_ID` 为你的环境 ID（唯一一处）。
3. 云开发控制台 → 数据库 → 建 **8 个集合**：


   ```
   users  schools  cats  sightings  tnr_records  tasks  funds  applies
   ```
   每个集合权限改为「**仅管理端可读写**」（安全规则 `{"read": false, "write": false}`）。所有读写走云函数，客户端无直连权。
4. 云存储建目录（如 `cat-photos/`、`avatars/`）备用。

> 详细见旧 `部署指南.md` 第 2/4 步（仅初始化部分仍有效）。

### 2.2 部署云函数 `catcampus`

1. 文件树右键 `cloudfunctions/catcampus` → **上传并部署：云端安装依赖**（约 1 分钟）。
2. 云函数 → 配置 → **环境变量**，按 §3 表格填（AI_TOKEN / AI_ENDPOINT / AI_TIMEOUT_MS 等；虚拟支付 VPAY\_* 未开通可留空）。

### 2.3 小程序上传与提审

- 改 `project.config.json` 的 `appid` 为你的；`app.js` 的 `ENV_ID` 已改。
- 隐私协议：小程序后台 → 用户隐私保护指引 → 配置（用户信息、位置信息、相册）。
- 提审文案 / 类目 / ICP 前置审批：**严格按「小程序上线申请指南」填**，关键避坑见 §4 合规红线。
- 提交审核（1–7 天）→ 发布。

### 2.4 识别服务 → 云托管（CloudBase Run）

1. 云开发控制台 → 云托管 → 新建服务（如 `catcampus-vision`）。
2. 新建版本 → **上传代码目录** → 选 `server/`（平台用里面的 `Dockerfile` 云端构建）。
3. 环境变量填 `API_TOKEN`（与云函数 `AI_TOKEN` 一致）；`PORT` 不用填（平台注入 80）。
4. **数据卷**：新建卷挂到容器路径 `/data`（特征库持久化，否则重启归零）。重新部署生效。
5. 开启**公网访问**，记下域名，如 `https://catcampus-vision-xxxx.ap-shanghai.run.tcloudbase.com`。

> 完整三种路径（上传目录 / 推 TCR / Git 自动构建）、规格、坑见 `识别服务云托管部署.md`。

### 2.5 管理后台 `web/`（可选）

- **路径 A（推荐同体系）**：Spring Boot 打镜像也走「云托管」，监听 `PORT`；MySQL 用云开发「云数据库 MySQL」或你自有实例。`application.yml` 的 `catcampus.vision.base-url` 填 2.4 的云托管域名。
- **路径 B（自有服务器）**：`server/` 同机用 `docker-compose` 起，或 Spring Boot + MySQL 直接跑。
- 个人项目最小上线可**先不部署 web 后台**（小程序 + 云函数 + 云托管识别已能对外服务），后台留本地/自有服务器运维用。

### 2.6 配置串联（上线最容易漏的一步）

| 配置点                                  | 填什么                   | 在哪                                |
| ------------------------------------ | --------------------- | --------------------------------- |
| 云函数 `AI_ENDPOINT`                    | `云托管域名/v1/recognize`  | 云函数环境变量                           |
| 云函数 `AI_TOKEN`                       | 与云托管 `API_TOKEN` 一致   | 云函数环境变量                           |
| 云函数 `AI_TIMEOUT_MS`                  | `15000`               | 云函数环境变量                           |
| 后端 `catcampus.vision.base-url`       | `云托管域名`               | `web/backend/.../application.yml` |
| 后端 `catcampus.vision.token`          | 与云托管 `API_TOKEN` 一致   | `application.yml`                 |
| 后端 `catcampus.vision.asset-base-url` | **后端对云托管可达的地址**（见下方坑） | `application.yml`                 |

> ⚠️ **猫照片可达性坑**：识别服务建库/识别时会下载猫照片。若后端在自有服务器，`asset-base-url` 必须填后端**公网可达**地址；若后端也上云托管（同环境），填后端云托管域名。填 `127.0.0.1:8080` 会让云托管取到它自己，建库必败。

## 3. 环境变量汇总

### 3.1 云函数 `catcampus` 环境变量

| 变量                                                                                                                                 | 必填 | 说明                              |
| ---------------------------------------------------------------------------------------------------------------------------------- | -- | ------------------------------- |
| `ENV_ID`                                                                                                                           | 是  | 云开发环境 ID（也可写死在 app.js，二者一致即可）   |
| `AI_TOKEN`                                                                                                                         | 是  | 与云托管 API_TOKEN 一致               |
| `AI_ENDPOINT`                                                                                                                      | 是  | `云托管域名/v1/recognize`            |
| `AI_TIMEOUT_MS`                                                                                                                    | 否  | 默认 15000                        |
| `VPAY_OFFER_ID` / `VPAY_APP_ID` / `VPAY_APP_SECRET` / `VPAY_APP_KEY` / `VPAY_SANDBOX` / `VPAY_MSG_TOKEN` / `VPAY_ENCODING_AES_KEY` | 否  | 个人虚拟支付，**MP 后台开通后填**；未填则虚拟支付不可用 |
| 数据库/存储相关                                                                                                                           | 否  | 云函数默认走当前环境，无需额外配                |

### 3.2 云托管 `catcampus-vision` 环境变量

| 变量                                                        | 必填 | 说明                     |
| --------------------------------------------------------- | -- | ---------------------- |
| `API_TOKEN`                                               | 是  | 强口令，与云函数 `AI_TOKEN` 一致 |
| `PORT`                                                    | 否  | 平台自动注入（80）             |
| `REID_ONNX` / `INDEX_DB` / `FETCH_TIMEOUT` / `MAX_FRAMES` | 否  | 镜像内已固定默认值              |

### 3.3 后端 `application.yml`（WEB 段）

```yaml
catcampus:
  vision:
    base-url: https://<云托管域名>      # 2.4 拿到的
    token: ${CAMPUS_VISION_TOKEN:<与云托管一致>}
    asset-base-url: https://<后端可达地址>   # 见 2.6 坑
    school-id: ${CAMPUS_VISION_SCHOOL:}
    timeout-seconds: 120
```

## 4. 上线前检查清单（含合规红线）

- [ ] `project.config.json` 的 `appid` 已替换（非 `touristappid`）
- [ ] `app.js` 的 `ENV_ID` 已替换
- [ ] 8 个集合已建，权限「仅管理端可读写」
- [ ] 云函数已上传并云端安装依赖
- [ ] 隐私协议已配置（用户信息 / 位置 / 相册）
- [ ] **ICP 备案已过**（发布硬性前提）
- [ ] **类目选「工具 → 信息查询」**（个人主体可选类目有限，以实际可选为准）
- [ ] **ICP 前置审批项选「以上都不涉及」**，提审文案避开「诊疗 / 培训 / 金融 / 售卖」等词
- [ ] 🚫 **小程序端不得出现「AI」字样** —— 改「智能匹配 / 花色比对」。AI / 深度合成类目仅企业主体可申请
- [ ] 识别服务云托管已部署、`/health` 返回 `provider:onnx`、`ffmpeg:true`
- [ ] 云托管数据卷已挂 `/data`（特征库不丢）
- [ ] **首次上线建一次特征库**（后端 `POST /api/vision/build-index` 或小程序端触发），确认 `built == 猫档案数`、`failed` 为空
- [ ] 虚拟支付：未开通则不调用 `pay()`；开通后先沙箱（`VPAY_SANDBOX=1`）联调
- [ ] `msgSecCheck` 内容安全权限已开通（用户发布文案/昵称过审要用）

## 6. 回滚与运维

- **云函数**：控制台「版本」可回退到上一版。
- **云托管**：服务「版本」可回退；缩容到 0 时首请求有 1–5s 冷启动（加载 ONNX），设最小副本 1 可消除。
- **特征库**：持久卷 `/data` 挂载，重启不丢；换模型后整体 `build-index` 重建。
- **费用**：云托管按 CPU/内存/流量按量计费，1 核 2G 起步月几十元；空闲缩容到 0 不收计算费。
