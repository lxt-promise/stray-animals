# 市场分析报告（2026-09）

## 一、大盘：为什么现在做

- 2025 年城镇宠物（犬猫）消费市场 **3126 亿元**（+4.1%），其中猫经济 1520 亿（+5.2%，增速超过犬）。宠物猫 7289 万只。
- 宠主结构：90 后 42.7% + 00 后 26.3% —— **高校学生正是未来 3-5 年的养宠主力与情绪消费核心**。
- 流浪猫：城市流浪猫千万级（上海一城约 40 万）。流浪的根源是遗弃与无序繁殖，校园是重灾区也是治理最可行的单元（边界清晰、人群配合度高）。
- 高校治理已有成功样本：武大 TNR 小分队（绝育 320+ 只）、长江大学知音猫社（百只降到 20 只）、北大猫协（2006 年至今）。**痛点高度一致：全靠 Excel + 微信群 + 自掏腰包。**

## 二、竞品拆解

### 1. 街猫（哈啰系，行业 TOP1）
- **模式**：智能猫屋硬件（2 万+ 台）+ 直播 + 云投喂 + TNR 众筹。登记猫 13.6 万只，绝育 6.7 万只。
- **强项**：硬件闭环、商业化跑通（爱心币 + 分成）、AI 猫脸识别建档。
- **致命伤（对我们是机会）**：
  - 高校动保组织**明确抵制**其进校（商业平台干扰公益救助、喂饱未绝育猫导致诱捕失效）；
  - 猫粮堆积发臭、小区业主对立、多地物业叫停；
  - 直播暴露猫位置 → 已发生多起虐猫者循定位投毒/投猫尸事件；
  - 重资产模式无法轻量复制到校园。
- 海外版 **Purrrr**（HI-BIKE HK）主攻东南亚，与我们无直接冲突。

### 2. Whisker Tracker（美国，2024 上线）
- **模式**：猫脸识别 + 猫档案 + 私有地图 + TNR 台账，面向救助志愿者。
- **参照价值**：验证了「TNR 数字化台账」是真实需求（其收费点就是数据导出与团队协作）。
- **短板**：极客向、无社交裂变；Google Play 安装量仅 500+；团队功能到 2027 年才完整。国内无人做同类。

### 3. CatchCat（德国独立开发，2026-06 上线）
- **模式**：拍照识别真猫 → 生成带稀有度的 3D 收藏卡，Pokémon GO 式。
- **参照价值**：零营销数天病毒传播，**验证了「游戏化 + 拍猫」是极强的拉新引擎**。这个机制可以被公益产品借用来解决「学生参与度」问题。
- **短板**：纯娱乐无公益内核，留存动机弱。

### 4. 北大猫咪图鉴（2019，校园鼻祖）
- **模式**：单校猫档案小程序，曾刷屏到服务器崩溃，已开源。
- **参照价值**：证明了校园猫档案的破圈能力。
- **短板**：单校工具，无协作层（TNR/排班/资金），无游戏化，无法复制到其他学校（开源代码但无人运维）。

### 5. 领养类平台（宠安家等）
信息聚合型，审核靠人肉，无校园场景深耕。不构成直接竞争，可做领养出口的合作方。

## 三、竞争格局结论

| | 街猫 | Whisker | CatchCat | 北大图鉴 | **喵园** |
|---|---|---|---|---|---|
| 校园场景 | ✗（被抵制） | ✗ | △ | ✓ | **✓** |
| 社团协作 | △ | ✓ | ✗ | ✗ | **✓** |
| 学生互动/游戏化 | ✓（直播） | ✗ | ✓ | △ | **✓** |
| 零硬件轻启动 | ✗ | ✓ | ✓ | ✓ | **✓** |
| 可复制到多校 | ✓（重资产） | △ | ✓ | ✗ | **✓（schoolId 隔离）** |

**生态位**：校园流浪猫治理的数字化基础设施。上游不与街猫抢云投喂市场，下游与领养平台互补。

## 四、风险与对策

| 风险 | 对策 |
|---|---|
| 虐猫者利用位置信息 | 点位隐私分级（幼猫/病猫默认模糊化），不做人肉定位展示，不做直播 |
| UGC 违规内容 | 云函数强制 msgSecCheck/imgSecCheck；打卡需登录 |
| 个人主体限制 | 不做支付/公开社区；内容工具属性为主；付费留待企业主体 |
| 冷启动无社团资源 | 先以「技术验证」身份找一所学校试点；产品内置入社申请流，帮社团把审核搬到线上本身就是谈判筹码 |
| 毕业季断代（社团换届） | 数据沉淀在平台而非个人 Excel/微信群里——这本身就是核心卖点 |
