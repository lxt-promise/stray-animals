# 喵园 CatCampus 识别服务 · 接口文档

> 服务代码：`server/`（FastAPI + ONNX Runtime），对外提供「图片 / 视频猫脸识别 + 特征库检索」。  
> 本文档与 `server/app/main.py` 逐字段对齐，可作为前端 / 后端 / 云函数对接的唯一依据。

---

## 1. 基础约定

### 1.1 服务地址

| 环境                 | 地址                                                        |
| ------------------ | --------------------------------------------------------- |
| 本地调试               | `http://127.0.0.1:8090`                                   |
| 云托管（CloudBase Run） | 平台分配的公网域名（如 `https://xxx.ap-shanghai.run.tcloudbase.com`） |

### 1.2 鉴权

除 `GET /health` 外，所有接口都要鉴权。请求头：

```
Authorization: Bearer <API_TOKEN>
```

- `API_TOKEN` 来自服务端环境变量，须与调用方（后端 `catcampus.vision.token` / 云函数 `AI_TOKEN`）**完全一致**。
- 若服务端 `API_TOKEN` 未配置（空），则所有接口对内网开放（仅调试用，生产务必设 token）。
- 鉴权失败返回 `401 invalid token`。

### 1.3 通用数据类型

- **CatRef（候选猫档案）**：识别 / 建库时由调用方带来，用于把「向量」映射回「猫」。
  | 字段        | 类型       | 说明                                                                       |
  | --------- | -------- | ------------------------------------------------------------------------ |
  | `id`      | string   | 猫的唯一标识（建议用后端猫ID），**建库后作为特征库主键**                                          |
  | `name`    | string   | 展示名，识别结果回显用                                                              |
  | `pattern` | string   | 花纹（辅助标签，如 tabby/solid），回显用                                               |
  | `color`   | string   | 毛色（辅助标签），回显用                                                             |
  | `photos`  | string[] | **可直接下载的绝对 URL 列表**（http/https）。识别服务在另一台机器时需公网/内网可达，不能是 `127.0.0.1` 指向自己 |
- **schoolId（校区隔离）**：留空表示全局库；多校区部署时传不同值，特征库与检索互不干扰。

### 1.4 状态码约定

| HTTP | 含义                                |
| ---- | --------------------------------- |
| 200  | 成功                                |
| 400  | 参数错误（如识别请求既无 `url` 也无 `videoUrl`） |
| 401  | token 无效                          |
| 502  | 素材下载失败（图片/视频 URL 不可达或解码失败）        |
| 5xx  | 模型加载 / 推理异常（看服务端日志）               |

## 2. 接口清单

| 方法     | 路径                | 鉴权 | 作用                        |
| ------ | ----------------- | -- | ------------------------- |
| GET    | `/health`         | 否  | 健康检查 + 引擎信息               |
| POST   | `/v1/recognize`   | 是  | **核心：识别一张图 / 一段视频，返回候选猫** |
| POST   | `/v1/embed`       | 是  | 单独抽一张图的向量（调试 / 建库脚本用）     |
| POST   | `/v1/index/build` | 是  | 批量把猫档案照片建成特征库             |
| DELETE | `/v1/index`       | 是  | 清空特征库（整体重建前调用）            |

## 3. 接口详解

### 3.1 `GET /health`

健康检查。部署后第一步先打这个，确认模型加载、ffmpeg 可用、特征库猫数。

**请求**：无

**响应字段**：

| 字段         | 类型     | 说明                                 |
| ---------- | ------ | ---------------------------------- |
| `ok`       | bool   | 恒为 true                            |
| `provider` | string | 当前特征引擎后端：`onnx` / `torch` / `hash` |
| `dim`      | int    | 向量维度（当前 DINOv2-base = 768）         |
| `ffmpeg`   | bool   | 是否检测到 ffmpeg（影响视频抽帧）               |
| `indexed`  | int    | 特征库当前猫数量                           |

**示例**：

```json
{ "ok": true, "provider": "onnx", "dim": 768, "ffmpeg": true, "indexed": 12 }
```

---

### 3.2 `POST /v1/recognize` ⭐

**核心接口**。输入一张图片或一个视频，返回特征标签 + 候选猫排序。

#### 请求体（`RecognizeReq`）

| 字段         | 类型       | 必填  | 说明                               |
| ---------- | -------- | --- | -------------------------------- |
| `url`      | string   | 二选一 | 图片可下载 URL（图片识别走这条）               |
| `videoUrl` | string   | 二选一 | 视频可下载 URL（配合 `type:"video"` 走抽帧） |
| `fileId`   | string   | 否   | 预留字段，当前未启用（微信云存储 fileId 需先换临时链接） |
| `type`     | string   | 否   | `image`（默认）或 `video`             |
| `frames`   | int      | 否   | 视频抽帧数，默认 1，上限 8（`MAX_FRAMES`）    |
| `schoolId` | string   | 否   | 校区隔离，留空=全局库                      |
| `cats`     | CatRef[] | 否   | 候选猫档案。识别服务特征库为空时会用这里的照片**冷启动补库** |

> 注：`url` 与 `videoUrl` 至少传一个，否则 `400`。

#### 响应字段

**`features`（本张图提的特征）**：

| 字段           | 类型       | 说明                                                                                |
| ------------ | -------- | --------------------------------------------------------------------------------- |
| `tags`       | object[] | 标签卡：`[{k:"毛色",v:"橘猫"},{k:"花纹",v:"tabby"},{k:"检测",v:"已定位猫体"/"整图"},{k:"帧数",v:"3"}]` |
| `pattern`    | string   | 花纹（CLIP 零样本分类，辅助展示）                                                               |
| `color`      | string   | 毛色（同上）                                                                            |
| `size`       | string   | 预留，当前恒空                                                                           |
| `confidence` | float    | 属性分类置信度（无 CLIP 时回退 0.75）                                                          |
| `embedding`  | float[]  | 查询向量（已 L2 归一化，维度 = `dim`）                                                         |

**`candidates`（候选猫，按相似度降序，最多 5 个）**：

| 字段       | 类型     | 说明                                           |
| -------- | ------ | -------------------------------------------- |
| `catId`  | string | 匹配到的猫 ID（来自 `cats[].id`）                     |
| `name`   | string | 猫名（来自 `cats[].name`）                         |
| `avatar` | string | 首图 URL（来自 `cats[].photos[0]`）                |
| `score`  | int    | **0~99 展示分**，由余弦相似度经 `SIM_LOW/SIM_HIGH` 标定映射 |
| `rawSim` | float  | 真实余弦相似度（0~1，保留 4 位）                          |
| `reason` | string | 文案，如「特征相似度 98.2%」                            |

**`meta`（元数据）**：

| 字段         | 类型     | 说明        |
| ---------- | ------ | --------- |
| `provider` | string | 引擎后端      |
| `frames`   | int    | 实际参与推理的帧数 |
| `latency`  | int    | 端到端耗时（毫秒） |
| `indexed`  | int    | 检索时特征库猫数  |

#### 请求示例（图片）

```bash
curl -X POST http://127.0.0.1:8090/v1/recognize \
  -H "Authorization: Bearer catcampus-local-dev-token" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "http://127.0.0.1:8080/uploads/cat/2026/abc.jpg",
    "type": "image",
    "schoolId": "",
    "cats": [
      {"id":"3","name":"小橘","pattern":"tabby","color":"橘猫",
       "photos":["http://127.0.0.1:8080/uploads/cat/2026/orange1.jpg"]},
      {"id":"7","name":"煤球","pattern":"solid","color":"纯黑",
       "photos":["http://127.0.0.1:8080/uploads/cat/2026/black1.jpg"]}
    ]
  }'
```

#### 请求示例（视频，抽 6 帧）

```bash
curl -X POST http://127.0.0.1:8090/v1/recognize \
  -H "Authorization: Bearer catcampus-local-dev-token" \
  -H "Content-Type: application/json" \
  -d '{"videoUrl":"http://cdn.example.com/clip.mp4","type":"video","frames":6}'
```

#### 响应示例

```json
{
  "features": {
    "tags": [
      {"k":"毛色","v":"橘猫"},
      {"k":"花纹","v":"tabby"},
      {"k":"检测","v":"已定位猫体"},
      {"k":"帧数","v":"1"}
    ],
    "pattern": "tabby",
    "color": "橘猫",
    "size": "",
    "confidence": 0.78,
    "embedding": [0.013, -0.027, 0.041, "…(共 768 个)…"]
  },
  "candidates": [
    {"catId":"3","name":"小橘","avatar":"http://127.0.0.1:8080/uploads/cat/2026/orange1.jpg",
     "score":99,"rawSim":0.982,"reason":"特征相似度 98.2%"},
    {"catId":"7","name":"煤球","avatar":"http://127.0.0.1:8080/uploads/cat/2026/black1.jpg",
     "score":12,"rawSim":0.745,"reason":"特征相似度 74.5%"}
  ],
  "meta": {"provider":"onnx","frames":1,"latency":407,"indexed":12}
}
```

#### 错误示例

```json
{ "detail": "url or videoUrl required" }   // 400
{ "detail": "素材下载失败" }                 // 502
```

### 3.3 `POST /v1/embed`

单独抽一张图的向量，用于建库脚本 / 调试，不经过检索。

**请求体（`EmbedReq`）**：

| 字段       | 类型     | 必填 | 说明                  |
| -------- | ------ | -- | ------------------- |
| `url`    | string | 是  | 图片 URL              |
| `detect` | bool   | 否  | 是否先用检测模型裁猫（默认 true） |

**响应**：

```json
{ "embedding": [0.01, -0.03, "…"], "dim": 768,
  "color": "橘猫", "pattern": "tabby", "detected": true }
```

---

### 3.4 `POST /v1/index/build`

**批量建库**：把档案里每只猫的多张照片平均成一个「代表向量」存入特征库。多张平均比单张稳（正面/侧面/光线差异被抹平）。

**请求体（`BuildReq`）**：

| 字段             | 类型       | 必填 | 说明                                     |
| -------------- | -------- | -- | -------------------------------------- |
| `schoolId`     | string   | 否  | 校区隔离                                   |
| `cats`         | CatRef[] | 是  | 要建库的猫（每只取 `photos` 前 `photosPerCat` 张） |
| `photosPerCat` | int      | 否  | 每猫取几张，默认 6                             |

**响应**：

| 字段       | 类型       | 说明                 |
| -------- | -------- | ------------------ |
| `ok`     | bool     |                    |
| `built`  | int      | 成功建库猫数             |
| `failed` | string[] | 建库失败的猫 ID（照片全下载失败） |
| `total`  | int      | 建库后特征库猫数           |

**示例**：

```bash
curl -X POST http://127.0.0.1:8090/v1/index/build \
  -H "Authorization: Bearer catcampus-local-dev-token" \
  -H "Content-Type: application/json" \
  -d '{"schoolId":"","photosPerCat":4,
       "cats":[{"id":"3","name":"小橘","photos":["http://.../o1.jpg","http://.../o2.jpg"]}]}'
```

```json
{ "ok": true, "built": 1, "failed": [], "total": 13 }
```

---

### 3.5 `DELETE /v1/index`

**清空特征库**，整体重建前调用。配合 `/v1/index/build` 实现「档案库即真相来源」——增删改猫后整体同步一次即完全一致。

**请求参数（query）**：

| 参数         | 类型     | 说明            |
| ---------- | ------ | ------------- |
| `schoolId` | string | 留空清全部；否则只清该校区 |

**响应**：

```json
{ "ok": true, "removed": 13, "remaining": 0 }
```

## 4. 典型调用流程

### 4.1 首次上线 / 新增猫后同步特征库

```
DELETE /v1/index            # 清空旧库（整体重建）
POST   /v1/index/build      # 用猫档案重建（后端「同步特征库」按钮即这两步）
```

### 4.2 识别一张用户上传的图

```
POST /v1/recognize { url, cats:[当前全部猫档案] }
  → 前端展示 candidates 里 score 最高的猫；score 低则提示「未匹配到，可人工确认」
```

> 特征库为空时，`recognize` 会用请求里的 `cats[].photos` 冷启动补库（限流 40 只/次），跑过一次 build 后基本不走这条。

## 5. 对接方须知（后端 / 云函数）

- **后端 `VisionService`**：代理 `/v1/recognize` 与 `/v1/index/build`，负责把后端相对路径 photos 补成识别服务可达的绝对 URL（配置 `catcampus.vision.asset-base-url`）。
- **云函数 `lib/vision.js`**：契约一致的旧版调用，切换为调用本服务时只需改 `AI_ENDPOINT` / `AI_TOKEN` 环境变量，前端零改动。
- **照片 URL 可达性**：识别服务在容器/其他机器时，`cats[].photos` 必须是它**能下载**的地址。若后端在本地而识别服务在云托管，`asset-base-url` 不能填 `127.0.0.1`——必须填云托管能访问到的公网/内网地址，否则建库报 502。

## 6. 换模型 / 调参（运维必读）

所有开关在 `server/app/config.py`，可用环境变量覆盖，不碰接口与前端：

| 改什么 | 环境变量 | 默认 | 说明 |
| --- | ---- | -- | -- |

| 换 ReID 骨干(ONNX) | `REID_ONNX`                                 | 空                                       | 指向新 `.onnx`；dim/输出形态自动适配                          |


| 换 timm 模型       | `REID_TORCH`                                | `timm/vit_large_patch14_dinov2.lvd142m` | 不设 ONNX 时自动走 PyTorch                              |  
| 输入尺寸            | `REID_SIZE`                                 | 518                                     | 模型输入分辨率                                           |  
| 检测模型            | `DETECT_ONNX`                               | 空                                       | YOLO onnx；猫类 id 在 `engine._Detector.CAT_CLASS=15` |  
| 毛色/花纹分类         | `USE_CLIP` + `CLIP_MODEL`/`CLIP_PRETRAINED` | 关                                       | CLIP 零样本；标签在 `config.COLOR_LABELS/PATTERN_LABELS` |  
| 设备              | `DEVICE`                                    | `auto`                                  | `auto`/`cpu`/`cuda`（自动探测 CUDA）                    |  
| 抽帧上限            | `MAX_FRAMES`                                | 8                                       | 视频最多抽帧数                                           |  
| 特征库路径           | `INDEX_DB`                                  | `/data/catcampus/index.sqlite3`         | **云托管务必挂卷到 `/data`**，否则重启归零                       |

**换模型后必做**：

1. **重建特征库**（DELETE + build）——旧向量维度/分布不兼容。
2. **重标定阈值**：`SIM_LOW=0.70 / SIM_HIGH=0.96` 是按 DINOv2 真实猫照定的（同猫 0.96~~0.996、异猫 0.745~~0.926）；换模型用 `tools/_realcat_probe.py` 重跑，否则会出现「任意两只猫都打 99 分」。
3. 重启服务加载新模型。

## 7. 当前默认配置（参考）

- 模型：DINOv2-base ONNX，输出 **768 维**，已打进云托管镜像（`models/reid.onnx`）
- 阈值：`SIM_LOW=0.70`，`SIM_HIGH=0.96`，`GAP_CLEAR=0.03`（Top1 与次名差 <0.03 压低分）
- 视频：ffmpeg 抽帧，速率按「时长/帧数」自适应，上限 4fps
- 归一化：ImageNet 均值方差
