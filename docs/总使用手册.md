# 喵园 CatCampus · 总使用手册

> 面向**管理员 / 运营 / 开发者**的一站式入口。技术细节分散在 `部署/` `识别服务/` `合规与上线/` 等分类文档，文末「文档导航」给出索引。
> 本文与 `部署/部署上线手册.md` 互为补充：本手册偏「怎么用、出了事怎么查」，部署手册偏「怎么一步步上线」。

---

## 0. 这是什么

**喵园 CatCampus** 是一个校园流浪猫**个体识别**小程序：用户拍一张猫的照片，服务把猫「比对」回档案里的某只猫，并展示花色、档案、打卡、TNR、积分等信息。

整套系统**完全跑在微信云开发体系内**，无需自购服务器、无需自有备案域名：

```
   微信小程序（原生，miniprogram/）
        │  仅与云函数通信
        ▼
   云函数 catcampus（单一云函数，表驱动 32 action）
        ├── 云数据库（15 集合）         users/schools/cats/sightings/tnr_records/
        │                              tasks/funds/applies/ai_tasks/ai_samples/
        │                              school_applies/points/levels/...
        ├── 云存储（猫照片 / 头像）
        ├── 识别服务（云托管容器）        POST /v1/recognize（server/）
        └── 虚拟支付（云函数内 vpay）    个人虚拟支付（需 MP 后台开通）
   管理后台 web/（Vue + Spring Boot + MySQL）★可选，非小程序必需
```

**个人主体可上线**是核心约束，由此衍生两条铁律：① 小程序端不得出现「AI」字样；② 不开微信支付（改用虚拟支付）。

## 1. 最小可用部署（三步）

### 1.1 云函数 `catcampus`
- 开发者工具右键 `cloudfunctions/catcampus` → **上传并部署：云端安装依赖**。
- 环境变量（见 §3）：`ENV_ID` / `AI_TOKEN` / `AI_ENDPOINT` / `AI_TIMEOUT_MS`；虚拟支付 `VPAY_*` 未开通留空。

### 1.2 小程序上传提审
- 改 `project.config.json` 的 `appid`、`miniprogram/app.js` 的 `ENV_ID`。
- 隐私协议（用户信息 / 位置 / 相册）、类目、ICP 前置审批严格按 `合规与上线/小程序上线申请指南.md` 填。
- **合规红线见 §4**，违反会被拒。

### 1.3 识别服务 → 云托管（关键，最易踩坑）
1. 云开发控制台 → 云托管 → 新建服务（如 `catcampus-vision`）。
2. 新建版本 → 上传代码包（用 `scripts/package_vision.py` 生成 `dist/catcampus-vision-YYYYMMDD.zip`，**不要直接压 `server/`**）→ 构建。
3. 环境变量：`API_TOKEN`（与云函数 `AI_TOKEN` 一致）。
4. **实例规格**：「最小副本数」设 **1**（消除冷启动；识别服务默认最小实例 1）；「最大实例数」**锁 1**（保证 `recocache` 与 COS 特征库单实例正确）。
5. **特征库持久化（二选一，必做其一）**：
   - 挂数据卷到 `/data`（`Dockerfile` 已固定 `INDEX_DB=/data/catcampus/index.sqlite3`，卷挂载即持久化）；
   - 或设 `INDEX_BACKEND=cos` + `COS_*` 凭证，向量存进腾讯云 COS，彻底不依赖容器磁盘。
6. 开「公网访问」，记下域名填云函数 `AI_ENDPOINT`。

> 详见 `部署/识别服务云托管部署.md`。**最小实例数=1 已设仍慢？** 见 §6.3（缩略图优化）。

### 1.4 （可选）管理后台 `web/`
个人项目可先不部署；小程序 + 云函数 + 云托管识别已能对外服务。后台 `application.yml` 的 `catcampus.vision.base-url` 填 1.3 的云托管域名。

## 2. 配置串联（环境变量）

| 配置点 | 填什么 | 在哪 |
| --- | --- | --- |
| 云函数 `AI_ENDPOINT` | `云托管域名/v1/recognize` | 云函数环境变量 |
| 云函数 `AI_TOKEN` | 与云托管 `API_TOKEN` 一致 | 云函数环境变量 |
| 云函数 `AI_TIMEOUT_MS` | `15000` | 云函数环境变量 |
| 云托管 `API_TOKEN` | 强口令，与云函数一致 | 云托管环境变量 |
| 云托管 `INDEX_BACKEND` | `cos`（推荐）/ 留空=sqlite（需挂卷） | 云托管环境变量 |
| 云托管 `MIN/MAX 实例数` | 最小 1 / 最大 1 | 云托管规格 |
| 后端 `catcampus.vision.base-url` | 云托管域名 | `web/backend/.../application.yml` |
| 后端 `catcampus.vision.token` | 与云托管 `API_TOKEN` 一致 | `application.yml` |

> ⚠️ 猫照片可达性坑：识别服务建库/识别时下载猫照片。若后端在自有服务器，`asset-base-url` 必须填**公网可达**地址；若后端也上云托管（同环境），填后端云托管域名。填 `127.0.0.1` 会让云托管取到它自己，建库必败。

## 3. 上线前检查清单（含合规红线）

- [ ] `project.config.json` 的 `appid` 已替换（非 `touristappid`）
- [ ] `app.js` 的 `ENV_ID` 已替换
- [ ] 15 个集合已建（**`school_applies` 是第 15 个，最容易漏**），权限「仅管理端可读写」
- [ ] 云函数已上传并云端安装依赖
- [ ] 隐私协议已配置（用户信息 / 位置 / 相册）
- [ ] **ICP 备案已过**（发布硬性前提）
- [ ] 类目选「工具 → 信息查询」；ICP 前置审批选「以上都不涉及」；提审文案避开「诊疗/培训/金融/售卖」
- [ ] 🚫 **小程序端不得出现「AI」字样** → 改「智能匹配 / 花色比对」（AI 类目仅企业主体可申请）
- [ ] 识别服务云托管已部署、`/health` 返回 `provider:onnx`、`ffmpeg:true`
- [ ] 云托管最小实例数=1、最大实例数=1；数据卷挂 `/data` 或 `INDEX_BACKEND=cos`
- [ ] **首次上线建一次特征库**（后端 `POST /api/vision/build-index` 或小程序端触发），确认 `built == 猫档案数`、`failed` 为空
- [ ] `msgSecCheck` 内容安全权限已开通（发布文案/昵称过审要用）
- [ ] 部署后调一次 `initCollections`（幂等，一键建 15 集合；用户首次进页读 `school_applies` 漏建会刷 `-502005`）

## 4. 合规红线（个人主体必读）

1. **不出现「AI」**：端上不写「AI」、档案页不展示识别置信度、确认识别不入特征库。审核驳回「社交-笔记」判定成立**不申诉**。详见 `合规与上线/审核驳回应对方案.md`。
2. **类目 / ICP**：类目选「工具 → 信息查询」；ICP 备案是发布硬前提（预留 4–6 周）；前置审批选「以上都不涉及」。
3. **内容安全**：用户发布文案 / 昵称走 `msgSecCheck`；图片走 `sec.checkImage`（识别链路里这步最慢，约 1.5–3s）。
4. **支付**：个人主体开不了微信支付，用虚拟支付（`技术/虚拟支付接入说明.md`）；未开通则不调用 `pay()`。

## 5. 首次上线后必做

- **建特征库**：档案照片向量必须建库，识别才有候选。空库时识别服务会用请求体 `cats[]` 里的照片冷启动补库（上限 `BOOTSTRAP_LIMIT`），但正式库要靠 `build-index`。
- **选校申请流**：用户选校走「申请 + 理由 + 管理员审核」（`school_applies` 集合）。选校下拉**默认只显示定位 25km 内学校**，附近无校引导去新建。详见 `业务规则/图鉴与学校绑定.md`。
- **积分 / 等级**：points 只增不减 + food 可减，日上限 150/50。详见 `业务规则/积分与等级规则.md`。

## 6. 日常运维与排错

### 6.1 健康检查
```bash
curl https://<云托管域名>/health
# 期望 provider:onnx、ffmpeg:true、indexed:猫数
```

### 6.2 特征库持久化
- 挂数据卷到 `/data` 或 `INDEX_BACKEND=cos` 二选一，否则容器重建特征库归零、识别退化。
- 换模型后整体 `build-index` 重建。

### 6.3 识别很慢（~15s）
进度条「0→92%」是前端氛围动画（不是真实进度），真实耗时在 92%→100%。

- **根因通常是跨服务下载原图**：原图常 3–10MB，识别服务出网拉要十几秒；ONNX 推理只要 ~0.2s/图。
- **已修复（2026-10-28）**：云函数换链时现拼 `imageMogr2/thumbnail/768x` 缩略图传给识别服务，服务端优先下缩略图、失败回退原图。总时长 15s → ~5s。
- **仍未达预期**：确认云托管「最小实例数=1」（无冷启动）；确认云托管与云存储**同地域**（跨地域出网仍慢）；看识别服务日志 `/v1/recognize %dms` 的 `total_ms` 验证。

### 6.4 质量门控（夜间 / 占比过小）
查询图需过「占比 + 低光」双维（`server/app/engine.py` 的 `_quality`）：
- 猫占比 < `QG_MIN_AREA_RATIO=0.06`（约猫占画面 1/4 以内随手拍）→ 不出候选、花色弃权；
- 猫体 crop 平均亮度 V < `QG_MIN_LIGHT_MEAN_V=125`（夜间 105/113 vs 白天 ≥178）→ 同上。
不通过时 `meta.qualityOk=false`、`qualityReason` 给原因，前端走「这张照片没法比对」。夜间近拍白猫误判黑猫即被此门控拦下，不污染候选。详见 `识别服务/识别不准排查手册.md` 八之五。

### 6.5 学校绑定 / 集合漏建
- 进页刷 `-502005 database collection not exists: school_applies` → 部署后调一次 `initCollections` 根治；代码已加集合缺失自愈（读路径返回空、写路径 `await` 建完再写）。
- 选校只显 25km → 设计如此（`geoDistanceM` 内存 Haversine 过滤，当前校常驻，无定位回退全部）。

### 6.6 回滚
- 云函数 / 云托管「版本」可回退到上一版。
- 费用：云托管按 CPU/内存/流量按量计费，1 核 2G 月几十元；空闲缩容到 0 不收计算费（但首请求有冷启动，故最小实例设 1）。

## 8. 一句话总结

喵园 = 小程序 + 云函数 + 云数据库/存储 + 云托管识别服务，个人主体可上线；上线前过合规红线、建集合、建特征库；运维盯 `/health`、特征库持久化、识别慢看缩略图与最小实例数、质量门控看夜间与占比。
